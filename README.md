# Введение

RU: Тестовый проект по написанию простенькой банковской системы. Создан для изучения docker, go, работа с базами данных и использованием телеграмм бота

# Структура

- 'src/': Содержит все основные файлы для бэкенда
    - 'bootstrap': Запуск приложения
    - 'controllers': Принимает запрос-ответы от http
    - 'domain': Объекты 
    - 'repository': Запросы в базу данных
    - 'services': Бизнес-логика системы

# краткое ТЗ

 - система авторизации и хранения аккаунтов.
 - система счётов. Различные виды, создание и закрытие.
 - автоматическая система получения сертификатов из центра сертификации.
 - Система переводов денег со счетов.
 - Система безопасности, для автоматического отслеживания подозрительных действий.
 - история переводов и статистика.
